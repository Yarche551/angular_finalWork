# АйтиШторм — сайт веб-студии (курсовая работа на Angular)

Сайт по макету `angular diploma.fig` и ТЗ из папки курсовой: главная, авторизация и регистрация,
блог с фильтром и пагинацией, страница статьи с комментариями и реакциями, политика конфиденциальности.

**Стек:** Angular 22.2 (standalone-компоненты, signals, zoneless, новый control flow `@if/@for`),
Reactive Forms, RxJS, SCSS, [ngx-mask](https://www.npmjs.com/package/ngx-mask) (маска телефона),
ESLint (angular-eslint), Vitest (unit-тесты).

## Запуск

Нужны Node.js 22+ и запущенная MongoDB на `localhost:27017`.

### 1. Бэкенд (из `Проект бэкенда.zip`)

1. Распаковать `Проект бэкенда.zip`, внутри — `project.zip`, распаковать и его.
2. Распаковать `images.zip` и скопировать все картинки в `project/public/images`.
   Файл `image3.jpg.jpg` переименовать в `image3.jpg` — иначе у одной статьи не будет картинки.
3. В папке `project`:

```bash
npm i
```

```bash
npx migrate-mongo up
```

```bash
npm start
```

Бэкенд поднимется на `http://localhost:3000`. Тестовый пользователь из миграции:
`test@gmail.com` / `12345678`.

### 2. Фронтенд (эта папка)

```bash
npm install
```

```bash
npm start
```

Сайт откроется на `http://localhost:4200`. Адрес API задан в `src/environments/environment.ts`.

### Остальные команды

| Команда         | Что делает                          |
| --------------- | ----------------------------------- |
| `npm run build` | продакшн-сборка в `dist/it-storm`   |
| `npm test`      | unit-тесты (Vitest)                 |
| `npm run lint`  | проверка кода линтером              |

## Структура

```
src/app
├── core
│   ├── auth            — AuthService (токены, имя пользователя), интерцептор, guard
│   └── scroll          — прокрутка к якорям после загрузки ленивых страниц
├── shared
│   ├── layout          — layout, шапка, подвал
│   ├── components      — карточка статьи, модалка заявки, snackbar, лоадер,
│   │                     пагинация, кастомный select, кнопка «показать пароль»
│   ├── directives      — закрытие выпадающих меню по клику снаружи
│   ├── services        — запросы к API, snackbar, управление модалкой заявки
│   └── utils           — правила валидации, пагинация, параметры фильтра в URL
├── types               — типы ответов backend
└── views
    ├── main            — главная
    ├── user            — вход и регистрация
    ├── blog            — список статей, страница статьи, комментарий
    └── policy          — политика конфиденциальности
```

## Что сделано по ТЗ

**Шапка и подвал**
- Логотип ведёт на главную, пункты меню — к блокам главной, «Статьи» — в блог и подсвечивается там.
- Телефон — ссылка `tel:`, e-mail — `mailto:`, иконки соцсетей — внешние ссылки.
- «Войти» для гостя; «Привет, имя!» с выпадающим меню «Выйти» для авторизованного.
- «Перезвоните мне» открывает модалку «Закажите бесплатную консультацию!» на любой странице.

**Формы и валидация**
- В каждой форме подсветка полей и текстовые сообщения об ошибках.
- Регистрация: имя — только русские буквы и пробелы, каждое слово с заглавной; корректный e-mail;
  пароль от 8 символов, минимум одна заглавная буква и одна цифра; обязательное согласие.
- Ссылки на соглашение и обработку данных открывают `/policy` в новой вкладке и прокручивают
  к нужному разделу.

**Главная**
- Слайдер из 3 акций (стрелки, точки, автопрокрутка); «Подробнее» открывает «Заявку на услугу».
- Карточки услуг: заявка с подставленной услугой, все поля обязательны, после успешной
  отправки — «Спасибо за вашу заявку!», при ошибке — красная надпись под кнопкой.
- О компании, популярные статьи с backend, слайдер отзывов, контакты с картой Яндекса.

**Блог**
- Статьи плитками с backend, «Читать дальше» ведёт на статью.
- Фильтр по категориям (несколько сразу, повторный клик снимает выбор), плашки выбранных
  категорий с крестиком, пагинация со стрелками; всё хранится в URL и переживает перезагрузку.

**Статья**
- Текст и картинка с backend, стили для HTML-разметки статьи, «Поделиться», «Читайте также».
- Комментарии: 3 последних, «Загрузить ещё» по 10 с лоадером, сообщение для гостей
  и для статей без комментариев, форма отправки для авторизованных.
- Лайк / дизлайк с подсветкой и snackbar «Ваш голос учтен», повторный клик снимает реакцию,
  переключение между лайком и дизлайком; реакции подтягиваются отдельным запросом при открытии.
- Жалоба: «Жалоба отправлена» / «Жалоба уже отправлена».

**Дополнительно**
- Показать/скрыть пароль, маска телефона, кастомный выпадающий список в заявке.
- Шаринг статьи во ВКонтакте и Facebook (для Instagram — копирование ссылки).
- Линтер, unit-тесты, адаптив до 375px, «умная» пагинация (`1 … 4 5 6 … 20`).
- Автоматическое обновление access-токена по refresh-токену при ответе 401.
